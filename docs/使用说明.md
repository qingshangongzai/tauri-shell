# 使用说明

轻壳有两条使用路径，按你的需求选择其一：

- **路径 ①「纯壳」** — 已有自己的网页，只想把它打包成 Windows 桌面程序。
- **路径 ②「同风格开发」** — 认可示例页的「去线留白」风格，想在这套设计语言与组件的基础上开发自己的应用。

> 设计语言的完整定义见 [“去线留白”设计语言.md](./“去线留白”设计语言.md)；安装器与托盘的专题说明见 [安装器说明.md](./安装器说明.md)、[托盘说明.md](./托盘说明.md)。

## 路径 ①：纯壳 — 打包你自己的 HTML

### 1. 替换页面

把你的网页内容写进 `dist/index.html`（单文件；如有额外静态资源需同时在 `minify.cjs` 的白名单中登记，见下方「构建产物白名单」）。

### 2. 标题栏取舍

轻壳默认是**无边框窗口 + 自绘标题栏**，替换 HTML 时二选一：

**方案 A：保留自绘标题栏**（推荐，观感与示例一致）

从原 `dist/index.html` 中保留这三部分，其余全部换成你的内容：

1. `<div class="titlebar">` 及其子元素（标题文字 + 最小化/最大化/关闭三键）；
2. 标题栏相关 CSS（`<style>` 中「自定义标题栏」分节，及设计令牌里的 `--titlebar-h`、`--titlebar` 等变量）；
3. 尾部 `<script type="module">` 中的「窗口控制」与「屏蔽浏览器加速键」两段逻辑——这是无边框窗口的拖拽、三键功能与防露馅措施。

> 偷懒版：直接以 `components/starter.html` 为底（已备齐上述三件套），把你的内容填进页面区即可，见路径 ②。

**方案 B：使用系统原生标题栏**

1. `src-tauri/tauri.conf.json` 中 `windows[0].decorations` 改为 `true`；
2. 删除 HTML 中的标题栏元素与相关 CSS/JS；
3. 注意：`plugin:window|show` 那行建议保留（配合 `visible: false` 避免启动白屏）。

### 3. 改名清单

#### 必改项

| 文件 | 字段 | 说明 |
|------|------|------|
| `tauri.conf.json` | `productName` | 应用名称 |
| `tauri.conf.json` | `identifier` | 唯一标识，建议 `com.xxx.yyy` |
| `tauri.conf.json` | `windows[0].title` | 窗口标题 |
| `tauri.conf.json` | `windows[0].width/height` | 窗口尺寸 |
| `Cargo.toml` | `name` | 内部名称（需与 `bin.name`、`lib.name` 一致） |
| `Cargo.toml` | `[package.metadata.tauri-winres]` 下所有字段 | Windows EXE 属性（右键文件 → 属性 → 详细信息） |
| `package.json` | `name` | npm 包名 |
| `dist/index.html` | `<title>`、`.titlebar-title` | 页面标题、标题栏文字 |
| `installer/src-tauri/src/config.rs` | 全部常量 | 安装器产品信息（显示名、exe 名、注册表键等，文件内有逐项说明） |
| `installer/src/product.ts` | 全部常量 | 安装器前端文案（与 `config.rs` 保持一致） |
| `installer/src-tauri/tauri.conf.json` | `productName` / `identifier` / 窗口 `title` | 安装器窗口信息 |
| `installer/src-tauri/Cargo.toml` | `[[bin]] name`（需等于 config.rs 的 `WIZARD_EXE_NAME` 去掉 `.exe`）及 `tauri-winres` 字段 | 安装器 EXE 名与属性 |
| `installer/index.html` | `<title>` | 安装器页面标题 |

#### 可选改动

| 文件 | 字段 | 说明 |
|------|------|------|
| `tauri.conf.json` | `version` | 版本号（`sync-version.cjs` 会自动同步到其他文件，只需改这一处） |
| `tauri.conf.json` | `windows[0].resizable` | 是否可调整大小 |
| `tauri.conf.json` | `windows[0].decorations` | `false`= 无边框 + 自定义标题栏，`true`= 系统原生标题栏 |
| `src-tauri/icons/logo.svg` | — | 替换为你的应用图标（正方形、透明背景 SVG），构建时自动生成 EXE 图标并同步给安装器 |

### 4. 构建命令速查

| 命令 | 产物 |
|------|------|
| `npm run tauri dev` | 开发预览，改 `dist/index.html` 自动刷新 |
| `npm run build` | 自带安装向导的单文件安装包（`dist-installer/`） |
| `npm run build -- --skip-main` | 只重打安装器，跳过主应用构建 |
| `npm run build:nsis` | NSIS 安装包（`src-tauri/target/release/bundle/nsis/`） |
| `npm run tauri build -- --no-bundle` | 裸 EXE（`src-tauri/target/release/`） |

### 构建产物白名单

打包只收录 `dist-min/` 下的文件，由 `minify.cjs` 白名单式生成：默认仅 `index.html`、`tray-menu.html` 两页 + `logo.svg`。若你的页面引用了其他静态资源，需在 `minify.cjs` 中补充拷贝；`components/` 目录仅是参考资料，**不进任何构建产物**。

## 路径 ②：同风格开发 — 复用设计令牌与组件

`components/` 目录是为这条路径准备的「参考组件库」：

| 文件 | 内容 |
|------|------|
| `tokens.css` | 「去线留白」设计令牌（浅色 + 深色 + 动效降级），可 link 或内联 |
| `starter.html` | 风格骨架模板：标题栏 + 可折叠侧边栏 + 页面切换 + 深色模式，掏空了示例功能 |
| `toast.html` | Toast 通知 demo（自动消失、三种类型、手动关闭） |
| `modal.html` | Modal 弹窗 demo（ESC / 遮罩关闭、退场动画、焦点圈禁） |
| `tabs.html` | Tab 标签页 demo（卡片内多组互不干扰） |
| `progress.html` | Progress 进度条 demo（确定 / 不确定两种状态） |
| `badge.html` | Badge / Tag 徽章 demo（纯 CSS） |
| `button.html` | Button 按钮 demo（主/次两种变体，纯 CSS） |
| `input.html` | Input 填充式输入框 demo（纯 CSS，无边框淡色底 + 聚焦加深） |
| `switch.html` | Switch 开关 demo（纯 CSS + 隐藏 checkbox） |
| `select.html` | Select 下拉选择器 demo（含定位翻转、外点关闭、键盘支持 JS） |
| `tooltip.html` | Tooltip 提示气泡 demo（纯 CSS，hover / 键盘聚焦） |
| `context-menu.html` | 自定义右键菜单 demo（键盘导航、复制粘贴置灰逻辑） |

每个 demo 都是**自包含单文件**：双击即可在浏览器里预览（含深浅主题切换按钮），不依赖 Tauri，也不依赖目录里的其他文件。

### 同步约定（重要）

`dist/index.html` 是**唯一权威源**（活体演示），`components/` 内是手动拆分的拷贝。两侧对应分节都写有「已拆出 / 拷贝自 …，改动请同步」注释——改任何一侧组件代码时，请把改动同步到另一侧。设计令牌则是三处同源：`dist/index.html`、`installer/src/styles/tokens.css`、`components/tokens.css`。

### 设计令牌速查

深色模式机制：所有令牌在 `[data-theme="dark"]` 下整体反转，JS 只需切换 `<html>` 的 `data-theme` 属性。

| 类别 | 令牌 | 用途 |
|------|------|------|
| 画布/表面 | `--bg` / `--sidebar` / `--card` / `--titlebar` | 页面底、侧栏、卡片、标题栏底色 |
| 交互底色 | `--hover` / `--divider` / `--input-bg` / `--input-bg-focus` | 悬停、按压、填充式输入框 |
| 强调色 | `--accent` / `--accent-bg` / `--accent-hover` / `--on-accent` | 主按钮、选中态、链接 |
| 语义色 | `--danger(-bg)` / `--warning(-bg)` / `--copy-success` | 错误、警告、成功 |
| 文字阶梯 | `--text-primary` (87%) / `--text-body` (78%) / `--text-auxiliary` (52%) / `--text-placeholder` (30%) | 用不透明度而非灰阶表达层级 |
| 动效 | `--ease` / `--duration-fast` (100ms) / `--duration-normal` (200ms) / `--duration-slow` (300ms) | 统一缓动与时长；已带 `prefers-reduced-motion` 降级 |
| 层级阴影 | `--shadow-card`（静置卡片）/ `--shadow-flyout`（浮层） | 弥散阴影代替边框线表达 elevation |
| 几何/字体 | `--radius` (10px) / `--radius-sm` (6px) / `--font` | 圆角与衬线字体 |

核心原则「去线留白」：不用边框线，用**留白、色块、弥散阴影**表达分隔与层级。新写的界面只要坚持从令牌取值、不写死颜色，即可自动获得深色模式与整体一致性。

### starter.html 上手流程

1. 复制 `components/starter.html` 覆盖 `dist/index.html`；
2. 改两处标题：`<title>` 与 `.titlebar-title`（正式改名再走路径 ① 的改名清单）；
3. `npm run tauri dev` 预览——此时已是带标题栏、侧边栏（首页/关于/设置）、深色模式开关的空应用；
4. 加页面按 starter 内「加页面三步」注释操作：加 `nav-item` → 加 `<section class="page" id="page-xxx">` → `PAGE_ORDER` 里登记页名；
5. 需要组件时按下方指引从 demo 复制。

> starter 的关闭按钮沿用了「按设置最小化到托盘」的逻辑；若已按 [托盘说明.md](./托盘说明.md) 移除托盘，把 `winClose` 的处理改为始终 `invoke('exit_app')`（文件内有注释标注）。

### 各组件复制指引

每个 demo 文件内用三段标题注释划出了「组件 CSS」「组件 HTML」「组件 JS」，把这三段搬进你的页面即可。前提：页面已引入设计令牌（tokens.css 或内联）。

| 组件 | 复制内容 | 额外依赖 | 调用方式 |
|------|----------|----------|----------|
| Toast | CSS + 挂载点 `#toastContainer` + JS | SVG symbol：`i-check` / `i-alert` / `i-x` / `i-info`；`--titlebar-h`（无标题栏页面设为 `0px`） | `window._showToast('success' \| 'warning' \| 'error', '文案')` |
| Modal | CSS + 遮罩层 HTML + JS | `.btn` 基础样式 | 任意按钮绑定 `openModal()`；ESC / 遮罩自动可关 |
| Tab | CSS + HTML + JS | `fadeSlide` keyframe（demo 已内联） | `data-tab` 指向面板 id；同页可放多组 |
| Progress | CSS + HTML | 无（JS 仅为演示加减） | 改 `.progress-bar` 的 `width` 并同步 `aria-valuenow`；不确定态加 `.progress-indeterminate` |
| Badge | 仅 CSS + HTML | 无 | 组合修饰类 `badge-accent/-success/-warning/-danger/-dot/-count` |
| Button | 仅 CSS + HTML | 带图标示例为内联 SVG（`.btn .icon` 固定 14px） | `.btn btn-primary`（强调色实心）/ `.btn btn-secondary`（中性色面） |
| Input | 仅 CSS + HTML | 无 | `.form-group` > `.form-label` + `.form-input`；不想要标签可只用 `.form-input` |
| Switch | 仅 CSS + HTML | 无 | `.toggle` 内藏原生 checkbox，无需 JS；带文字行用 `.toggle-row` 包裹 |
| Select | CSS + 挂载点 + JS | `flyoutPopIn` keyframe（demo 已内联）；chevron 为内联 SVG，无 symbol 依赖 | `createSelect(host, options, { value, ariaLabel, onChange })` |
| Tooltip | 仅 CSS | 图标按钮示例需 `.icon` + `i-info` symbol | 任意元素加 `class="tooltip" data-tip="提示文字"`，上方留出气泡空间 |
| 右键菜单 | CSS + 菜单 HTML + JS | `flyoutPopIn` keyframe（demo 已内联）；symbol：`i-copy` / `i-clipboard` / `i-arrow-up` / `i-moon` / `i-info` | 全局接管 `contextmenu` 事件；菜单项在 JS 尾部按需增删 |

对应代码在 `dist/index.html` 中的位置：CSS 见 `<style>` 内「UI 组件：×××」「自定义右键菜单」分节，JS 见尾部 `<script>` 内同名分节——每处都有「已拆出 components/×××.html」标记，可直接搜索定位。

### 想要更完整的底子？

如果示例页的某个整页（工具页、仪表盘等）接近你的需求，也可以反向操作：直接在 `dist/index.html` 上删掉不要的页面与对应 JS 分节，保留骨架与需要的部分——所有分节都有 `═════` 标题注释，按注释成段增删即可。

## 示例页多语言（i18n）机制

示例页内置简体中文 / English / 日本語三语切换（设置页「语言」下拉，选后即时生效并持久化到 localStorage 键 `tauri-shell-lang`）。零依赖字典方案，全部代码内联在 `dist/index.html` 脚本区的「多语言（i18n）」分节：

- **字典** `I18N`：`{ 'zh-CN': {...}, 'en': {...}, 'ja': {...} }`，语义化键名（如 `nav.dashboard`）；HTML 中的中文原文即兜底，键缺失时回退 zh-CN、再缺失则保持现状不报错。
- **静态文案**：元素加 `data-i18n="键名"`（替换 textContent）或 `data-i18n-html`（含内联标签时）；属性文案用 `data-i18n-attr="placeholder:键名;aria-label:键名2"` 声明。
- **动态字符串**：JS 中统一走 `t('键名', { n: 值 })` 取词，支持 `{n}` 占位符；切语言时广播 `app-localechange` 事件，需要重绘的动态模块（如 Select 演示、在线状态）监听它刷新。
- **增删词条**：三语字典同步增删同名键即可；**新增语言**：在 `I18N` 补一份完整字典 + 设置页语言下拉加一项；**移除 i18n**：删掉该分节与语言下拉即可，页面回退为纯中文。
- **托盘菜单** `dist/tray-menu.html` 另有一份内联小字典 `TRAY_I18N`（仅两菜单项），与主窗口共享同一 localStorage 键，每次弹出时重读并按文案重测窗口尺寸。
- 品牌与专名不译：应用名「轻壳」、Tauri、快捷键 kbd 键名保持原文；选项 label 用各语言自称（native name）。

> `components/*.html` 与 `starter.html` 是中文参考资料，不包含 i18n；路径 ① 替换整页后此机制随示例页一同被替换，无需额外处理。
